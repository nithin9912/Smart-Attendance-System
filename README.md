# Smart Attendance System

A real-time **face recognition-based attendance system** developed using **Python, Flask, CNN, OpenCV, HTML, and CSS**.

## Features

* Real-time face detection and recognition
* New user registration
* Automatic attendance marking
* Records user name, ID, date, and time
* Web-based interface using Flask

## Technologies Used

* Python
* Flask
* CNN
* OpenCV
* HTML
* CSS
* Bootstrap

## How It Works

The system captures a user's face through a camera, detects and recognizes the face using **OpenCV and CNN**, and automatically records attendance with the user's details and time.

## Run the Project

```bash
pip install -r requirements.txt
python app.py
```

Then open:

```text
http://127.0.0.1:5000/
```
